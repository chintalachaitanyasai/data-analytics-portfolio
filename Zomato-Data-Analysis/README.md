# Zomato Data Analysis

## Project Overview
Analyzed Zomato restaurant data to identify trends and patterns in restaurant ratings, pricing, cuisines, locations, and customer preferences.

## Tools & Technologies
- Microsoft Excel
- SQL
- Power BI
- Tableau

## Key Activities
- Performed data cleaning and transformation
- Analyzed restaurant and customer-related data using SQL
- Created KPIs and business metrics
- Performed exploratory data analysis
- Developed interactive dashboards using Power BI and Tableau
- Identified trends and insights to support data-driven decision-making

## Project Outcomes
Generated actionable insights into restaurant performance, customer preferences, pricing patterns, ratings, and location-based trends through data analysis and visualization.
